Você é um engenheiro de software sênior especialista em arquitetura full stack, aplicações musicais, interfaces educacionais e produtos SaaS. Sua tarefa é criar o MVP de uma plataforma web chamada provisoriamente **Hinário Inteligente**, voltada ao estudo de hinos do Santo Daime com foco em ensino musical interativo.

# OBJETIVO DO PRODUTO

Construir uma plataforma web moderna onde o usuário possa:

* importar arquivos **MusicXML / MXL** de partituras de hinos
* visualizar a partitura no navegador
* reproduzir o hino
* **mudar o tom** de forma dinâmica
* alterar BPM
* repetir trechos em loop
* escolher tipos de acompanhamento
* estudar com apoio de uma **IA pedagógica**
* futuramente usar microfone para comparar execução/canto com a partitura

O sistema deve ser pensado como algo semelhante ao Guitar Pro ou um player de estudo musical, porém **especializado em ensino de hinos**, com abordagem simples, bonita, moderna e intuitiva.

# DIRETRIZES DE PRODUTO

O foco não é só renderizar partitura. O foco é ser uma **plataforma pedagógica musical**.

O sistema deve permitir:

1. Estudo visual da partitura
2. Estudo auditivo com playback
3. Ajuste de tonalidade
4. Ajuste de andamento
5. Acompanhamento configurável
6. Assistente inteligente que ajuda o aluno a praticar

A IA deve ser implementada inicialmente como uma camada de orientação pedagógica baseada no conteúdo do hino e nas ações do usuário, sem depender de reconhecimento de áudio em tempo real no MVP inicial.

# ESCOPO DO MVP

## Funcionalidades obrigatórias do MVP

### Biblioteca de hinos

* cadastrar hinos no sistema
* listar hinos em tela
* visualizar detalhes do hino
* armazenar:

  * título
  * número
  * autor
  * tom original
  * andamento
  * compasso
  * categoria
  * tags
  * arquivo MusicXML ou MXL

### Visualização da partitura

* exibir a partitura no frontend a partir do MusicXML
* destacar compasso atual durante playback, se possível
* layout responsivo

### Reprodução

* reproduzir o hino
* play/pause/stop
* seek simples se a biblioteca suportar
* mostrar andamento atual

### Transposição

* permitir transposição por semitons
* botão para subir tom
* botão para descer tom
* exibir tom atual
* manter tom original salvo

### Controle de andamento

* alterar BPM
* resetar para BPM original

### Loop de estudo

* permitir selecionar início e fim de trecho simples
* repetir trecho

### Tipos de acompanhamento

Criar um sistema inicial de acompanhamento em presets:

* somente melodia
* melodia + metrônomo
* melodia + acordes básicos
* melodia + acompanhamento simples de violão
* melodia + pad suave opcional

Mesmo que a geração musical real seja simulada ou parcialmente limitada no MVP, a arquitetura deve ser preparada para expansão.

### IA pedagógica inicial

Criar um assistente dentro da plataforma que:

* analise os metadados do hino
* gere dicas de estudo
* sugira prática mais lenta
* sugira repetição de trechos
* explique dificuldade do hino
* responda perguntas sobre:

  * tom
  * andamento
  * compasso
  * dificuldade
  * ordem de estudo
  * dicas para violão/canto

Essa IA pode inicialmente funcionar via regras + prompts estruturados + contexto do hino.

# INTELIGÊNCIA ARTIFICIAL NO MVP

Criar um módulo chamado `pedagogical-assistant`.

Esse módulo deve:

* receber dados do hino
* receber estado atual de estudo do usuário
* gerar orientações práticas

Exemplos:

* "Este hino parece mais fácil para voz do que para violão"
* "Tente estudar primeiro em 70% do andamento"
* "Repita os compassos 4 a 8 antes de tocar inteiro"
* "O tom atual está 2 semitons acima do original"
* "Para iniciantes, sugerimos acompanhamento básico"

Implementar esse módulo de forma desacoplada para depois poder integrar:

* LLM externo
* análise por áudio
* recomendação personalizada por histórico
